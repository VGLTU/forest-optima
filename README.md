# Информационно-аналитический комплекс «Лес-Оптима» (Forest-Optima v1.0)

Программный комплекс многокритериальной оценки, математической нормализации и сценарного моделирования эффективности лесопользования в малолесных регионах.

Разработано для государственной регистрации в Федеральной службе по интеллектуальной собственности (Роспатент) как результат интеллектуальной деятельности (РИД — Программа для ЭВМ) и публикации в журналах Перечня ВАК / RSCI.

**Правообладатель:** ФГБОУ ВО «Воронежский государственный лесотехнический университет имени Г.Ф. Морозова» (ВГЛТУ).  
**Авторы:** Лесных И., Зиновьева И.С., Бурмистров А.М.

## 2. Математические основы

### 2.1. Нормализация разноразмерных показателей
Физические показатели ($x_1$ — запас древесины, тыс. м³; $x_2$ — площадь, га; $x_3$ — дороги, км) приводятся к безразмерному диапазону $[0, 1]$:
$$x'_{ij} = \frac{x_{ij} - \min_k(x_{kj})}{\max_k(x_{kj}) - \min_k(x_{kj})}$$

### 2.2. Метод взвешенной суммы (WSM)
$$I_{\text{WSM}} = \sum_{j=1}^m w_j \cdot x'_{ij}, \quad \sum_{j=1}^m w_j = 1$$

### 2.3. Метод TOPSIS (Евклидово расстояние до идеала)
$$D_i^+ = \sqrt{\sum_{j=1}^m w_j (1 - x'_{ij})^2}, \quad D_i^- = \sqrt{\sum_{j=1}^m w_j (x'_{ij} - 0)^2}, \quad C_i = \frac{D_i^-}{D_i^+ + D_i^-}$$

### 2.4. Социо-эколого-экономическая матрица Эйлера-Венна
Оценка предприятий по триединому критерию устойчивости ($0 \le S \le 15$):
- **$S \ge 11.0$**: Высокий уровень (рациональное лесопользование);
- **$6.0 \le S < 11.0$**: Средний уровень (допустимое развитие);
- **$S < 6.0$**: Низкий уровень (кризисное состояние).

## 3. Быстрый запуск

### Запуск вычислений и формирование Excel:
```bash
python3 run.py
```

### Запуск с пользовательскими весами:
```bash
python3 run.py --stock-weight 0.4 --area-weight 0.3 --roads-weight 0.3
```

### Запуск модульных тестов:
```bash
pytest -v
```

## 4. Веб-интерфейс и многопользовательская персистентность

Программный комплекс оснащен веб-интерфейсом на базе FastAPI и интерактивного SPA-калькулятора.
- **Изолированные рабочие пространства (Workspaces):** Каждый пользователь получает уникальную сессию с постоянным URL вида `?w=ws_abc123`.
- **Автосохранение:** Изменения в таблицах, весах и параметрах мгновенно рассчитываются на клиенте и синхронизируются с сервером (SQLite в режиме WAL).
- **Экспорт отчетов:** Поддерживается прямая выгрузка в форматированный Excel (.xlsx) и CSV (UTF-8 BOM).

### Локальный запуск веб-сервера:
```bash
python3 server.py
# Откройте браузер по адресу: http://localhost:8890
```

### Развертывание в Docker Compose:
```bash
docker compose up -d --build
```
Сервис запустится в изолированном контейнере с пробросом порта `127.0.0.1:8890:8890` и монтированием каталога `./data` для хранения базы данных SQLite.
